收起 ≠ 关闭：最小化（macOS 黄灯）把窗口收成胶囊；关闭（红灯）关掉窗口，不留胶囊。两者都不会停止智能体。
在主窗口打开 / 继续：发送后的任何状态都可用。主窗口选中这个会话，迷你窗口关闭，未发送的草稿带过去。
不变的部分：翻译、解释、总结等助手动作，仍走原来的一次性结果窗口。

入口：划词工具栏

沿用 SelectionToolbarView 的样式

窗口外壳

没有标题栏色带 · 整窗一种背景（popover）

窗口状态

指令条 560×150（高度随内容）· 对话窗口默认 560×620，最小 420×480 · 以 macOS 为例

胶囊

最小化或失焦后，窗口收成屏幕右下角的胶囊 · 各平台统一

关窗与主应用

关窗不停止 · 会话持久化保存，在主应用可见

设置

划词助手设置页 → 功能

规则速查

详细说明见 prd.md 第 6 节

状态失焦（开启自动关闭时）黄灯 / 最小化Esc在主窗口打开新的划词触发
待输入（有草稿）不关闭不可用不响应不可用另开窗口
待输入（空）关闭不可用关闭不可用复用这个窗口
启动中 / 运行中收成胶囊收成胶囊停止可用另开窗口
待批准收成胶囊收成胶囊拒绝（审批卡片）可用另开窗口
完成 / 错误关闭收成胶囊关闭可用复用这个窗口
已收成胶囊———恢复后可用不复用
尺寸指令条 560 宽，高度随内容（约 150）。对话窗口默认 560×620，最小 420×480；「记住窗口大小」开启时，单独记住对话窗口的尺寸。
沿用的窗口能力置顶、自动置顶、透明度、位置跟随工具栏，和现有结果窗口一致。指令条展开时，顶边位置不变，向下长高。
复用的组件AgentSelector、WorkspaceSelector、AgentToolCallCard、PermissionRequestComposer、消息渲染。能否嵌进独立窗口由 Spec 评估（见 #20207）。
Token整窗 popover；引用用 reference；待批准用 warning-subtle；错误用 error-subtle；主操作按钮用 emphasis（中性色），不用品牌绿。
